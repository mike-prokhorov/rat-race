# 🐭 Крысиные бега — финансовый тренажёр

Реалистичный симулятор денежного потока по идее **Cashflow** (Кийосаки), но про твою
жизнь: каждый ход — месяц в Да Нанге, свои цифры дохода и расходов, реальные решения —
подушка, долги, активы, навыки, отдых. Никакого кубика: выигрываешь только решениями.
Свобода = **пассивный доход больше расходов**.

Играть вместо TikTok в дороге и качать финансовое мышление.
Классическая версия с доской и кубиком сохранена: [/classic/](https://mike-prokhorov.github.io/rat-race/classic/).

## Запуск

Никакой сборки. Три способа:

```bash
# 1. просто открыть файл
open index.html

# 2. локальный сервер
python3 -m http.server 8642   # → http://localhost:8642

# 3. GitHub Pages (с телефона)
# https://mike-prokhorov.github.io/rat-race/
```

## Как играть

1. На старте впиши СВОИ доход и расходы — игра считает твой реальный поток.
2. Каждый месяц приходят 2-3 возможности (боты, недвижка, бумаги, связи) и иногда соблазн.
3. Предупреждения («байк просит ТО») чини вовремя — иначе ударит в разы дороже.
4. Свободные деньги — твоё решение: актив / долг / навык (+к доходу) / отдых (без него выгорание −25%).
5. Кассовый разрыв закрывается займом под 2%/мес — долги растут сами. Долг $30k = банкротство.
6. Три финала: 🏆 свобода · 💀 долги догнали · ⏳ тридцать лет в бегах.
7. После каждого решения — урок одной фразой. Это и есть обучение.

## Под капотом

- Vanilla JS, ноль зависимостей, движок отделён от UI (`js/engine.js` гоняется в node)
- Баланс целиком в `js/data.js` — правится без кода
- Смоук-тест: `node test/smoke.js` — 3 стратегии × 400 партий: транжира банкрот в 100%, инвестор свободен за ~4 года, рандом — за ~15 лет. 0 крашей
- Дизайн: «ночной банкирский стол» — сукно, золото, слоновая кость

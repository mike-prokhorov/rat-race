«Когда я где-то еду или кого-то жду — я хочу открыть телефон и играть в игру, которая
качает мою финансовую грамотность, а не залипать в TikTok. Что-то типа "Крысиных бегов"
Кийосаки, но сделанное красиво — как Monopoly One».

## Чему учит (педагогика зашита в механику)

1. **Кэшфлоу важнее зарплаты** — врач с $13k зарплаты выходит из бегов ТЯЖЕЛЕЕ дворника (расходы растут с доходом).
2. **Активы = то, что кладёт деньги в карман** — недвижимость/бизнес/дивиденды двигают прогресс, акции без дивидендов — только спекуляция.
3. **Соблазны (doodads) — тихий убийца** — обязательные траты бьют по наличным, игрок чувствует боль.
4. **Кредит — инструмент и ловушка** — 10% с тела каждый payday: рычаг для сделок или спираль вниз.
5. **Подушка безопасности** — увольнение = полные расходы из кармана + пропуск хода.

## 10 причин провала (убито заранее)

1. Скучно после 2 партий → 8 профессий с разным балансом + случайные колоды.
2. Непонятны правила → карточки объясняют на человеческом, лог проговаривает каждое событие.
3. Не запускается без интернета → vanilla JS, один открытый index.html, шрифты с фолбэком.
4. Выглядит как поделка → дизайн-система «ночной банкирский стол», эталон Mugen.
5. Невозможно выиграть → смоук-тест: 1000 партий ботом, каждая профессия выигрываема.
6. Слишком легко → банкротство реально (бот-жадина банкротится в 30% партий).
7. Неудобно на телефоне → мобильная раскладка: доска сверху, финансы под пальцем.
8. Игрок не понимает «зачем» → прогресс-бар выхода + финальный экран с уроком.
9. Утечка математики (NaN, минус в никуда) → движок отделён от UI, инварианты в тесте.
10. Забросим код → GitHub + доки по фазам, продолжить может любая сессия.

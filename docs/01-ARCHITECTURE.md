# Архитектура (фаза 2 Смыслокода)

## Правила проекта (проверяемые)

1. Движок не знает про DOM — `engine.js` гоняется в node без браузера.
2. Любой файл ≤ 800 строк, любая функция ≤ 50.
3. Ноль внешних JS-зависимостей — игра открывается с file:// и с GitHub Pages.
4. Баланс меняется только в `data.js` — код не трогаем ради цифр.
5. Каждое изменение движка → `node test/smoke.js` зелёный (0 крашей, все профессии выигрываемы).
6. Весь UI-текст на русском, деньги в формате `$1 234`.

## Что строим

Одностраничная браузерная игра. Три экрана: выбор профессии → доска → финал.
Никакого сервера: статика, состояние живёт в памяти вкладки.

## Сущности (общий словарь)

| Термин | Что это |
|---|---|
| Профессия | Стартовый набор: зарплата, расходы, наличные (баланс из Cashflow 101) |
| Payday | Проход через клетку «Зарплата»: cash += доход − расходы |
| Кэшфлоу | Доход (зарплата + пассивный) минус расходы, за круг |
| Актив | Недвижимость / бизнес / депозит / дивидендные акции — даёт пассивный доход |
| Соблазн (doodad) | Обязательная трата, случайная карта |
| Рынок | Событие: покупатель на актив, обвал/ралли акций, рост аренды |
| Выход из бегов | Пассивный доход > расходов = победа |

## Структура кода

```
index.html          разметка трёх экранов
css/tokens.css      дизайн-токены (палитра, шрифты, движение)
css/board.css       доска, клетки, фишка, кубики
css/panels.css      интро, финпанель, карточки, лог
js/data.js          ← ВЕСЬ баланс: профессии, колоды, клетки, правила
js/engine.js        чистая логика (Game): ходы, сделки, банк, победа/банкрот
js/ui.js            рендер, анимации, карточки-модалки
js/main.js          точка входа
test/smoke.js       автобот: 1000 партий, инварианты
docs/               эта документация
```

## Поток данных

```
клик «Бросить кубик»
  → engine.roll()            движок меняет состояние, возвращает события
  → ui: фишка шагает         (анимация по клеткам, payday-вспышка)
  → engine.snapshot()        UI рендерит ТОЛЬКО снапшот, не лезет в state
  → pendingCard?             модалка сделки/рынка/благотворительности
  → решение игрока           engine.buyStock/buyProperty/pass/...
```

Инвариант: UI никогда не пишет в `game.state` напрямую — только методы движка.

## Стек и почему

- **Vanilla JS (ES5-совместимый), без сборки** — открывается везде, включая file:// и
  WebView будущего мобильного приложения. Нет node_modules = нечему протухать.
- **CSS-анимации, только transform/opacity** — 60fps на телефоне, prefers-reduced-motion учтён.
- **Шрифты Google Fonts (Unbounded + Golos Text + JetBrains Mono)** — кириллица,
  характер; фолбэк на системные, если сети нет.
- **mulberry32 RNG с сидом** — детерминированные партии в тестах.

## Риски

| Риск | Ответ |
|---|---|
| Баланс скучный/жестокий | Весь баланс в data.js, крутится без кода; смоук меряет winrate |
| prompt()-диалоги банка выглядят бедно | Осознанный долг MVP; заменить на модалки в след. итерации |
| WebView-обёртка для стора | Кандидаты: Capacitor (см. SMYSLOKOD-STATUS, фаза «мобилка») |
